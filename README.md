# Gustavo Salgado

**AI Engineer · Agents in the cloud and on the desktop · Full Stack**

I build AI agents that do real work: they run on a server or on the user's own computer, call tools
on both sides, and stay observable and under control. 13+ years shipping software — mostly
JavaScript/TypeScript, also Python and Go — on AWS with infrastructure as code.

### What I work on

- **Agent runtimes** — the same agent design in TypeScript and Python behind one contract: a turn
  state machine, tool calls with idempotency and retries, questions back to the human, durable event
  streams you can replay.
- **Multi-provider** — Anthropic, OpenAI and others behind one `Models` port; swap the model, keep
  the agent.
- **Cloud and local** — the runtime runs as a Node server, as a Lambda, or inside an Electron app on
  the user's machine. Tools execute on the server *and* on the client (the user's files, apps, shell).
- **Infrastructure** — AWS (ECS, EKS, Lambda, API Gateway), Terraform, CI/CD pipelines. With the
  cloud as the default, the bottleneck is the spec, not the deploy.
- **Product** — I have also worked as a Product Manager. I write the definitions, not only the code.
